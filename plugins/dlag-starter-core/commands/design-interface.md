# Design Interface

This is the Starter Build Studio interface workflow. Load `dlag-starter-core:design-foundation` or read the [packaged Playbook](../skills/design-foundation/SKILL.md) and [Specialist instructions](../agents/design-foundation.md) directly.

Read existing design context and the scoped surface. Preserve the approved direction; ask one batch only for missing choices that change the work. For an already requested local implementation, write the relevant files using available Write/Edit tools, then read them back. Use the registered Specialist only if available and delegation is authorized. Otherwise follow the procedure directly and identify direct use.

Return changed paths, plain-language design reasons, interaction states, observed checks and unrun browser checks. Do not install design engines or dependencies, run executable commands, configure providers, read secrets, upload, commit, push, deploy or publish. Source examples are illustrative and do not prove an application renders.
