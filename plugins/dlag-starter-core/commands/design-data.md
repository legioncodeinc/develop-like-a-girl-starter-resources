# Design Data

Load `dlag-starter-core:data-foundation` or read its [packaged Playbook](../skills/data-foundation/SKILL.md), procedure and template directly. Use the [paired Specialist](../agents/data-foundation.md) only when available and delegation is authorized; otherwise perform direct use with the same limits.

Produce the smallest useful schema, operation matrix, indexed ownership references, RLS USING/WITH CHECK rules and explicit refusal cases. Save a local SQL draft or worksheet only when requested; inspect destinations and preserve existing files. Never apply migrations, install a client, access credentials, change a hosted database, commit, push or claim native isolation proof from SQL text. Read the [edition boundaries](../references/edition-boundaries.md).
