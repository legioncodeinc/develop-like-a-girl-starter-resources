# Recovery and exit qualification

A local design document is distinct from a restoration operation. Use existing provider and object-store evidence without reading secret values or invoking a restore.

1. Define recovery point and recovery time objectives with the owner. Record data classes, retention, region and business dependencies. Goals are requirements, not vendor guarantees. Inventory Supabase database rows/constraints/policies, Supabase Auth configuration/identity continuity, R2 object bytes/metadata, existing search projections and any accepted external state.
2. Verify backup coverage per service and actual plan. A PostgreSQL backup cannot restore independent R2 object bytes. Record where backups are retained, available restoration targets, downtime behavior, retention and encryption/access owners. A successful snapshot or enabled backup setting is not a restore rehearsal.
3. Draft a separately authorized isolated rehearsal with a synthetic fixture manifest. Check rows, constraints, policies, ordinary-user denials, object checksums, identity/session behavior and consumer continuity. Record rehearsal date, exact revisions, data size and observed timing. Existing credentials, hosted restoration, capacity purchases or provider writes require their own authorization.
4. Inventory exit dependencies beyond SQL: extensions/versions, auth identity/session migration, R2 buckets/object references, existing realtime or background integrations if present, egress quantity/cost, endpoints, privileged roles and operational secret purposes. Preserve accepted service ownership. An additive cutover needs explicit reconciliation and rollback criteria, not guessed backfills or destructive cleanup.
5. Deliver recovery coverage by stateful service, target versus observed RPO/RTO, blockers and export/reimport limits. A database restore can leave object references missing or stale; verify both directions. Security Review evaluates access/sensitive-data consequences before Quality Review checks an authorized implementation. Never replace a failed rehearsal with a vendor promise.
