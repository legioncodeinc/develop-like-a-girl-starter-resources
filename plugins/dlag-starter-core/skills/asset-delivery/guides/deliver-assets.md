# Deliver the assets the page needs

Inventory each requested image: purpose, actual file, natural dimensions/aspect ratio, displayed width at breakpoints, crop, alt text, above/below fold and public/private classification. Use an empty alt for purely decorative imagery and meaningful text for content images. An SVG from an untrusted upload needs separate sanitization/security treatment before inline use.

Use `img` with width/height so layout can reserve space. Use CSS max-width and automatic height for proportional resizing. Provide srcSet with width descriptors only for real variants of the same crop. Derive sizes from the actual container, padding and grid gaps, including a final fallback. A card in a two-column desktop grid is not 100vw. Browsers choose candidates using their own heuristics; do not promise one exact resource solely from arithmetic. Use picture/source for deliberate crop changes or format fallback, preserving appropriate aspect ratio for each crop. React uses srcSet and fetchPriority prop names.

Keep a likely LCP hero eager and consider fetchPriority="high" for the primary candidate. Below-fold imagery can use loading="lazy" and decoding="async". Do not lazy-load the primary hero or mark every image high priority. Confirm network and layout in the actual browser before claiming a gain. Keep a useful fallback source. Prefer a suitable modern format when actual derivatives exist; do not flatten alpha artwork or delete originals.

For fonts record the approved family, license, required languages/glyphs, weights and actual WOFF2 files. Keep the license with redistributed fonts and do not remove glyphs needed by the audience. Prefer the existing hosting arrangement or a system fallback when no font is supplied. Use an explicit font-display decision: swap gets text visible with potential layout movement; optional can keep the fallback on slower loads. Neither guarantees zero CLS. Preserve a usable system stack and readable text when font requests fail.

Preload only a small number of genuinely critical files when justified by the page. The URL must match the @font-face source and use as="font", type="font/woff2" and crossOrigin="anonymous" in JSX. Integrate the link with the existing React Router root/head convention. For cross-origin R2 font files, correct CORS headers must already be configured; this Playbook does not configure the bucket. Fallback metric tuning with size-adjust/ascent/descent overrides requires real measurements of the chosen pair. Never fabricate percentages to claim a match.

Return exact markup/CSS edits and observed checks. File dimensions, response headers, network priority, hydration, layout shift and font loading are separate evidence. A source-only review records runtime checks as unrun. Keep conversions and provider operations as named missing prerequisites rather than adding a pipeline without authorization.

For the complete method, open [font delivery](../fonts/playbook.md) or [image delivery](../images/playbook.md). The [font checklist](../fonts/guides/06-performance-checklist.md), [font report format](../fonts/reports/README.md) and [image audit template](../images/templates/image-audit-report.md) supply the detailed inventory and verification records. Optional conversion and subsetting code is an operator recipe with explicit prerequisites; this Playbook grants no shell or provider execution.
