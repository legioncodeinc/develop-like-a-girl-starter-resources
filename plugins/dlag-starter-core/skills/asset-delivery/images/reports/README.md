# Record image delivery findings

Use the consuming project's existing report folder and a filename such as `YYYY-MM-DD-project-image-audit.md` when a full audit was requested. Use [the complete template](../templates/image-audit-report.md): scorecard, inventory, format breakdown, responsive sizes, LCP attribution, placeholders and dimensions, prioritized corrections, impact and limitations.

For a focused markup correction return the changed paths and observed checks inline. Do not create a report folder in an installed Playbook for each use. Preserve the actual measurement conditions and distinguish source review, local conversion, network/browser evidence and field performance. Keep private signed URLs, object keys and original private images out of a public report.
