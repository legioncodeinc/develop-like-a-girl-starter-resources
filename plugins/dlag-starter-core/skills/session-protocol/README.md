# Work Session Protocol guide map

Use [the Playbook](SKILL.md) to keep the owner's task, deadline, attempts, worker ownership and checked evidence continuous across a work session.

- Read [the complete operating instructions](references/agent-instructions.md) before work.
- Use [the procedure](guides/procedure.md) to apply the method within actual tools and permissions.
- Use [the recovery worksheet](references/recover-after-compaction.md) after context compaction without resetting the allowance.
- Consult [clarifications and illustrative cases](references/origin-and-examples.md) for short tasks, deadlines, retries and evidence limits.
- Close with [the result template](templates/result.md).
- [Optional Claude Code context reference](references/session-start-hooks.md) describes context injection separately from enforcement. No hook is installed or activated.

This Core capability reads supplied local evidence and returns guidance in chat. It does not acquire execution or write tools from the operating protocol. Missing capabilities, unfinished work and unperformed checks stay explicit.
