# Official references

Consult the application's pinned versions before applying an API. Links are documentation, not dependencies or proof that a package is installed. Checked during authoring on 2026-10-20 Eastern; no upgrade is selected.

- [React effects](https://react.dev/reference/react/useEffect): synchronization, cleanup and server rendering constraints.
- [React state identity](https://react.dev/learn/preserving-and-resetting-state): component type, position and keys.
- [React useActionState](https://react.dev/reference/react/useActionState): browser Action state, queue and transition requirements; it does not create a server endpoint.
- [React useOptimistic](https://react.dev/reference/react/useOptimistic): optimistic state within the appropriate Action/transition lifecycle.
- [React Compiler installation](https://react.dev/learn/react-compiler/installation): inspect compatible build/plugin configuration and output before claiming activation.
- [React Router data loading](https://reactrouter.com/start/framework/data-loading): server loaders and framework data flow.
- [React Router actions](https://reactrouter.com/start/framework/actions): route mutation handlers.
- [React Router pending UI](https://reactrouter.com/start/framework/pending-ui): navigation/fetcher states.
- [React Router error boundaries](https://reactrouter.com/how-to/error-boundary): route failure UI.
- [React Router server modules](https://reactrouter.com/api/framework-conventions/server-modules): private module boundaries in the actual framework build.
- [React Router streaming](https://reactrouter.com/how-to/suspense): Suspense for real streamed work.

The templates and code fences require the stated installed dependencies and application contracts. They are not compiled applications, deployments or integration receipts.
