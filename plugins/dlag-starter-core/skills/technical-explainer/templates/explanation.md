# Explanation template

## Meaning

Explain the supported outcome in plain English.

## How the pieces connect

Preserve actors, conditions, order, refusal, time limits, and status. Include one fictional worked example and label it as illustrative.

## Analogy and limits

Use one consistent comparison. State what it cannot explain or prove.

## Words to know

Define only terms needed for this explanation.

## Sources and unknowns

Cite the supplied source by line or section. List unresolved facts and avoid claiming code execution.

## Check my explanation

Ask one respectful question that invites the reader to explain the important relationship in their own words. State that understanding is pending.
