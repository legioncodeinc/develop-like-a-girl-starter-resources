# Starter Build Studio local platform and design foundation

Twenty-six Core Playbooks and Specialists are packaged: eleven shared methods, thirteen Starter platform/design methods, Browser Checks and TypeScript/HTTP implementation guidance. Ten public commands are available. Website Builder and App Builder are separate plugins requiring this Core. Marketing and optional Business Tools remain unavailable.

Commands: `/dlag-starter-core:get-started`, `/dlag-starter-core:review-project`, `/dlag-starter-core:plan-project`, `/dlag-starter-core:manage-repository`, `/dlag-starter-core:explain-this`, `/dlag-starter-core:check-dependencies`, `/dlag-starter-core:build-task`, `/dlag-starter-core:ready-check`, `/dlag-starter-core:design-data`, `/dlag-starter-core:design-interface`.

New Starter foundation Specialists may make authorized local source and document edits using Read, Grep, Glob, Skill, Write and Edit. They have no shell, network/provider, deployment, hook or MCP tools. The three existing document Specialists keep their narrower document-writing scope; the eight existing read-only Specialists stay read-only. Provider configuration, dependency installation, credentials, sending email and publishing require separate express authorization and suitable tools.

The [availability roster](references/available-capabilities.md) gives exact names and scopes. Native installation and static checks establish packaging, not a successful app build or live integration. Existing Core model evidence remains limited to its tested historical artifact. No new model behavior sessions were run for this candidate.
