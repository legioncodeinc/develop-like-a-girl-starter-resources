# Starter Website Builder

Install dlag-starter-core from the same marketplace first, then this plugin. The Website Builder requires Core planning, design, platform and Browser Checks Playbooks. Invoke `/dlag-starter-website-builder:build-website`. Cross-pack calls use namespaced Skills, never sibling cache paths. If a required Core Playbook is unavailable, stop and report the prerequisite.

The Specialist can edit authorized local source and documents. Shell, browser execution, dependency installation, provider setup and deployment require a suitably equipped caller and existing owner authorization. Static and native packaging checks do not establish a successful website build or live operation.
